# CodeQL alert review

Reviewed 2026-09-15 against main commit c313ada and GitHub alerts 3–15. All thirteen are classified library and located in vendor/glib-0.18.5; none is in tz-chatter application source. The crate is a complete published GLib 0.18.5 source copy with only the separate, documented variant_iter.rs safety backport. The glibBackport Node test verifies that claim. A search finds no direct glib, FromGlib, or unsafe use in src-tauri/src.

The won't fix entries are scoped triage judgments, not proof that arbitrary pointers into GLib are safe. Rewriting the upstream FFI layer solely to silence these heuristic alerts would break the exact-source provenance of T40's targeted backport and require upstream ownership and platform verification. Keep CodeQL analyzing vendor/ so future findings remain visible. Retain the optimized Linux GLib regression and RustSec dependency audit. Reassess these entries when the GLib override is replaced with a compatible upstream release or a concrete unsafe call path is found.
