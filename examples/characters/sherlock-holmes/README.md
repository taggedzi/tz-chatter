# Sherlock Holmes

## A Visitor at Baker Street

Bring an unfinished thought, a small mystery, or simply yourself. Holmes has a chair available and a question worth asking.

An original literary portrayal based on Arthur Conan Doyle's stories, designed to demonstrate personality, source-backed background, reusable scenes, and memories formed through conversation.

![Original illustration of Sherlock Holmes](assets/portrait.png)

## Start in the app

1. Open **Characters → Meet Sherlock Holmes**.
2. Choose a parent folder and click **Create my Holmes**. The app creates a new sherlock-holmes child folder and selects it. Existing folders are never overwritten; use **Add** to reopen a copy you already created.
3. Select an already-installed local model in **Settings → Provider**. No model download, account, embedding model, or character-specific override is required by this pack.
4. Open **Chat**, introduce yourself, and begin in **221B Baker Street — A new visitor**.

Suggested first message: **“Good afternoon, Mr. Holmes. Before I bring you a puzzle, what makes a useful observation?”**

The playable files and portrait are embedded in the app, so packaged installations need neither a checkout nor network access to create Holmes. This directory also has a portable-pack manifest: import it through Settings → Vault to a fresh destination, then add that destination in Characters. Chat in a personal copy to keep tracked examples pristine.

## Explore

- “What does Norbury mean to you?” — fallibility and sourced background.
- “What do you keep in a Persian slipper?” — a specific domestic detail.
- “Was Irene Adler your lover?” — a recognizable misconception.
- “The letter disappeared, so the clerk must have stolen it.” — insufficient evidence.
- “No case today. What would you like to talk about?” — personality beyond detective performance.

Choose **An evening by the fire** or **Correspondence** from the scene selector. The latter tests the absence of physical observation. Your persona remains editable under Characters → You.

No conversation transcript, user-specific memory, unresolved case, provider credential, or initiative setting is preloaded. Canonical background is labeled fiction. The memory demonstration starts when the user supplies something new.

Recognizing Holmes tests portrayal; it does not prove retrieval. Inspect Sources and test a novel conversation detail in a **new chat**. Extraction and portrayal depend on the selected model.
